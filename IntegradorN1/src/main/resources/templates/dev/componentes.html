E0-03

Kit de componentes

Componentes Thymeleaf reutilizables para las vistas públicas y administrativas de Zero.

Mensajes

Alertas flash de éxito y error.

<div th:replace="~{fragments/mensajes :: mensajes}"></div>

Tabla

Listado genérico con acciones configurables y estado vacío.

<div th:replace="~{fragments/tabla :: tabla(${encabezados}, ${filas}, ${verUrl}, ${editarUrl}, ${eliminarUrl})}"></div>

Formulario

Campos de texto, selección, checkbox, errores y acciones.

<form th:replace="~{fragments/formulario :: formulario(${action}, 'post', ${errorNombre}, ${errorEmail})}"></form>

Tabla de registros

Listado de ABM con varias columnas, edición por fila y baja con modal.

 <div th:replace="~{fragments/tabla :: tablaRegistros(${encabezados}, ${registros}, ${baseUrl})}"></div>

Campos de formulario

Texto, selección y acciones sueltos, para formularios de ABM con varios datos.

<div th:replace="~{fragments/formulario :: campoSelect(${nombre}, ${etiqueta}, ${opciones}, ${seleccionado}, ${requerido})}"></div> <div th:replace="~{fragments/formulario :: campoTexto(${nombre}, ${etiqueta}, ${valor}, ${requerido})}"></div> <div th:replace="~{fragments/formulario :: acciones(${cancelarUrl})}"></div>

Selección agrupada

Select con opciones agrupadas, para elegir un registro según su padre.

<div th:replace="~{fragments/formulario :: campoSelectAgrupado(${nombre}, ${etiqueta}, ${grupos}, ${seleccionado}, ${requerido})}"></div>

Modal de confirmación

Confirmación reutilizable para una baja lógica.

<div th:replace="~{fragments/modal-confirmar :: modal(${id}, ${titulo}, ${mensaje}, ${actionUrl})}"></div>

Paginación

Navegación visual para listados y reportes.

<nav th:replace="~{fragments/paginacion :: paginacion(${paginaActual}, ${totalPaginas}, ${baseUrl})}"></nav>

Card de producto

Producto responsive con imagen, precio y oferta.

<article th:replace="~{fragments/card-producto :: card(${imagen}, ${nombre}, ${precio}, ${enOferta})}"></article>

Badge de estado

Estados definidos por los enums reales de OrdenCompra y Factura.

<span th:replace="~{fragments/badge-estado :: badge(${estado})}"></span>

Filtros

Barra adaptable con rango de fechas, estado y búsqueda.

<form th:replace="~{fragments/filtros :: filtros(${action})}"></form>

Filtro por selección

Filtra un listado por un solo valor, por ejemplo el registro padre.

<form th:replace="~{fragments/filtros :: filtroSelect(${action}, ${nombre}, ${etiqueta}, ${opciones}, ${seleccionado})}"></form>

KPI

Indicador configurable para dashboards.

<article th:replace="~{fragments/kpi :: kpi(${titulo}, ${valor}, ${descripcion}, ${icono})}"></article>
